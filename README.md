# RFBSocial — uma comunidade que é realmente sua

> **Estado atual: blueprint e identidade conceitual.** Este repositório ainda não contém um aplicativo implementado. Não há deploy nem testes funcionais.

Comunidades temáticas, grupos estudantis e criadores precisam de uma experiência própria para publicar, seguir pessoas, comentar e moderar conteúdo com controles de privacidade.

## Jornada proposta

1. Criar perfil e configurar visibilidade.
2. Publicar texto ou imagem autorizada.
3. Interagir por comentários e respostas.
4. Moderar denúncias e preservar privacidade.

## Galeria visual

Ainda não há capturas reais. As quatro telas planejadas são: feed, perfil, comentários e moderação. Uma futura implementação deve produzir 3–6 screenshots reais com data, ambiente, SHA e viewport, nunca prints falsos.

## Arquitetura e documentação

O Starter Pack inicial e especificação estão no repositório privado do RFB Method, na pasta `portfolio/projetos/03-rfbsocial/`. A meta é trabalhar com infraestrutura gratuita quando os limites permitirem; tecnologias e QA ainda não estão homologados.
